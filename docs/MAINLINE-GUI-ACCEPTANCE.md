## A. 收藏 → 整理

1. 添加 `http://127.0.0.1:39439/article/new`，手填标题“主线验收 A”，不选分类。应出现在待整理收件箱，后台抓取不能覆盖人工标题；列表不是只剩定位单条的锁定结果。
2. 再添加 `/article/quick-extra` 的完整同域 HTTP URL，手填“主线验收 B”。收件箱可同时看到多条。使用“选择当前页”后批量移动至“主线整理”、批量添加标签“主线验收”；列表/计数随整理变化，错误不能假报成功。
3. 再收藏完整 `/article/design` URL：应明确为已有项并定位它，不产生副本，不覆盖其原标题/笔记。
4. 再收藏完整 `/article/trashed` URL：先应出现回收站重复提示，不得静默恢复。测试“查看回收站”；再添加并明确恢复，原笔记“回收站笔记需要保留”、旧标签仍在。
5. 多个链接粘贴进单条 URL 输入应有引导去批量粘贴；非 HTTP 协议/含账号密码 URL 应拒绝。HTTP URL 路径大小写保持原样。

## B. 找回 → 阅读 → 复用

1. 在收件箱搜索已整理的“主线验收 A”：应说明当前范围无匹配，并提供“在全部收藏中搜索”；点击后找到 A。当前关键字/标签/域名/日期等条件在筛选摘要中可见、可逐个移除或清除全部。
2. 勾选 A 后改变筛选条件，旧选择必须清空，避免误操作隐藏项；目录内清除条件仍留在该目录，“在全部收藏中搜索”才扩展范围。
3. 打开 A，在“我的笔记”输入“笔记 A：可复用结论”。停输入约 700ms 或 Ctrl+Enter/失焦应显示“已保存”。再输入补充，立即切到 B 并写“笔记 B：另一条结论”；反复切换，不能串写。手动关闭并重启，同一库中两条笔记都正确。
4. “复制笔记”复制当前编辑内容；等待已保存后“复制引用”应有真实标题、网址、标签和已保存笔记。可粘贴到测试输入框核验，不向外发送。
5. 无 AI 配置时，在无关目录/筛选下打开收藏助手查询“设计系统”。应明确是关键词结果、不是 AI 总结；引用按钮可 Tab/Enter 打开，清理旧筛选并定位真实收藏；“复制引用”带真实来源。

## C. 真实模型增强与失败路径（小模型不代表中文质量达标）

设置中已有**关闭**的本机测试模型配置：Base URL `http://127.0.0.1:39441/v1`，模型 `zhicang-local-test`；无账户、无鉴权，Key 字段是字面量占位符 `local-test-not-a-secret`，不是真实密钥。按需打开并测试连接、保存，查询真实收藏。模型只有 135M，若生成没有合法引用或越界引用，产品应拒绝展示那段生成文本并给出明确关键词降级；不得标为高质量 AI 总结。将 Base URL 临时改为未监听的 `http://127.0.0.1:39442/v1` 后请求，应该清楚失败并保留真实关键词引用；最后恢复原 URL 或关闭 AI。

## D. 真扩展 GUI（必须人工操作，不使用浏览器自动化）

共享磁盘空间临界；Chrome 测试 profile 放 7.9GB 临时内存盘，与真实浏览器/账户隔离。其内容重启机器会消失，不作正式备份。

```bash
google-chrome --no-sandbox --disable-gpu --no-first-run --no-default-browser-check --user-data-dir=/dev/shm/zhicang-mainline-chrome-20261122 http://127.0.0.1:39439/article/extension
```

1. GUI 打开 `chrome://extensions`，开启开发者模式、“加载已解压的扩展程序”，选择 `/workspace/zhicang-mainline-review-20261122/extension-chrome`（manifest 在目录根部）。不用真实账户或同步。
2. 桌面设置的插件/MCP 桥接端口初始为 **38131**，应运行。仅在 GUI 中复制隔离库的桥接令牌至扩展选项（不要在日志/回复打印令牌）。扩展端口38131，测试连接通过后点保存。
3. 在真实文章页 `/article/extension` 打开扩展弹窗，应显示“已连接桌面端（令牌已验证）”，不是 vundefined。点收藏：桌面出现真实新收藏；再次点应提示已在收藏、不重复。桌面阅读/存档检查有真实正文（存档是异步操作）。
4. 扩展中故意填错误测试令牌，测试连接及收藏应明确鉴权失败，绝不显示成功。重新复制正确令牌并保存。
5. 关闭桌面桥接，扩展连接/收藏失败（提交最长10s结束，不能永远转圈）；重新开启可恢复。桌面改端口38132，扩展仍38131时失败；改为38132并保存后恢复。重置令牌后旧令牌失败，重新复制新令牌恢复。
6. 手动关闭/重启桌面；桥接端口/开启状态持久，扩展重新连接并可继续收藏。本轮仅本机通信，不能据此宣称 Windows/线上同步通过。
